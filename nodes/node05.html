NODE 07 - SIGNAL FRAGMENT

As the VORTEX servers began collapsing under PROTOCOL ZERO, investigators intercepted a damaged transmission hidden inside the syndicate’s communication relay. The engineer’s note reads: “Numbers can speak when converted correctly.”

Decode the following ASCII decimal sequence to recover the hidden keyword: 112 114 111 116 111 99 111 108

Each number represents the decimal ASCII value of a character. Convert them one by one to reveal the hidden word.
